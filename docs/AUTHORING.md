# Google Docs 編寫規範 (SOP)

本文件說明如何在 Google Docs 內編寫內容，讓系統可以正確轉成 MasterSlides 簡報。

## 轉換流程（背景知識）

```
Google Docs → 匯出為 Markdown → 上傳到 MasterSlides → 自動分頁顯示
```

- Google Docs 透過「下載 → Markdown (.md)」匯出
- 系統把 Markdown 轉成 HTML
- Pagination 引擎依字數與圖片**自動分頁**（不需要手動切頁）

---

## 1. 文件分享設定（必做）

文件必須設為 **「擁有連結者均可檢視」**（Anyone with the link can view）。否則系統讀不到內容。

```
檔案 → 共用 → 一般存取權 → 知道連結的任何人 → 檢視者
```

---

## 2. 標題（Heading）

⚠️ **內文絕對不要使用「標題 1」(Heading 1)。內文最高層級只能用「標題 2」。**

### 為什麼？

Google Docs **文件名稱**（畫面最上方那個檔名欄位）本身就等同整份文件的 Heading 1 ——它已經是這份文件的「主標題」。如果你在內文又加 Heading 1，等於同一份文件出現兩個主標題，文件結構錯亂。

正確的層級對應：

| 角色 | Google Docs |
|---|---|
| **整份文件的主標題（H1）** | 上方「文件名稱」欄位（檔名） |
| 章節 / 第一層分段 | **標題 2** (`##`) |
| 子節 / 第二層分段 | **標題 3** (`###`) |
| 更細的小標 | 標題 4 (`####`)，極少用 |
| 短句強調 | **粗體**（Cmd/Ctrl + B） |

### 範例

```markdown
## 第一章 緣起

### 一、釋題

正文段落...

### 二、源流

正文段落...

## 第二章 ...
```

文件最上方的檔名（例如「慈悲三昧水懺」）才是 H1；內文從 `##` 開始。

### Google Docs 對應操作

選取文字 → 樣式選單 → 「**標題 2**」或「**標題 3**」。  
👉 **樣式選單裡的「標題 1」永遠不用**。

### ⚠️ 給用 AI 起草內容的人

請在指令中明確告訴 AI（例如 ChatGPT、Claude）：「文件內最高只能用 Heading 2，禁止 Heading 1」。AI 很常以為要在內文加 `# 大標題`，這會造成上述問題。

---

## 3. 段落與換行

- 兩個段落之間**空一行**
- 同段內想換行：直接按 Enter（系統有開啟 `breaks: true`，單一換行也會生效）

```markdown
這是第一段。

這是第二段。
段內換行也可以。
```

---

## 4. 文字樣式

| 樣式 | Markdown | Google Docs 操作 |
|---|---|---|
| 粗體 | `**粗體**` | Cmd/Ctrl + B |
| 斜體 | `*斜體*` | Cmd/Ctrl + I |
| 刪除線 | `~~刪除~~` | 格式 → 文字 → 刪除線 |

⚠️ Google Docs 的「底線」、「字體色彩」、「螢光筆色」匯出 Markdown 時**會遺失**，請改用粗體 / 標題 / 強調段落表達重點。

---

## 5. 清單

### 無序清單（項目符號）

```markdown
- 第一項
- 第二項
  - 子項目（縮排 2 空格）
- 第三項
```

### 有序清單（數字編號）

```markdown
1. 第一步
2. 第二步
3. 第三步
```

### Google Docs 對應操作

工具列上的「項目符號清單」與「編號清單」按鈕。注意：**清單前後務必空一行**，否則匯出時可能被併入前段。

---

## 6. 圖片

**直接在 Google Docs 拖曳貼上即可。** 系統會：

1. 把圖片從 Google 抓下來
2. 上傳到 Drust 儲存
3. 自動同步圖片，下次再「同步」會清掉舊圖片

### 注意事項

- 支援格式：PNG / JPEG / GIF / WEBP
- 不要用「插入 → 影像 → 來自網址」直接連結到外部網站的圖（外部 URL 不會被匯出成 base64）
- 圖片大小過大會拖慢首次同步；建議單張 < 2 MB
- 圖片**在直書模式下會被當圖片元件**處理，自動置中、不會被切割

---

## 7. 表格

直接用 Google Docs 內建的「插入 → 表格」即可。

⚠️ **直書模式下表格特殊處理**：
- 表格會被 `html2canvas` **轉成圖片**後再分頁，否則中文直書會把表格內文字也轉成直書，視覺上很怪
- 因此**表格不能太寬**（建議欄數 ≤ 4，每欄文字 ≤ 20 字）
- 表格內**不要再放圖片**（圖片裡有圖片時 html2canvas 行為不穩）

### Markdown 範例（給直接寫 Markdown 的人）

```markdown
| 項目 | 說明 |
|---|---|
| 第一 | xxx |
| 第二 | yyy |
```

---

## 8. 連結

```markdown
[顯示文字](https://example.com)
```

或直接貼 URL，Google Docs 會自動處理。連結在簡報內可點擊，但點擊時會在**新分頁**開啟（避免離開簡報）。

---

## 9. 區塊引用 / 強調段落

```markdown
> 這是一段引用。常用於經文、法語、註解。
```

Google Docs 對應：選取段落 → 樣式 → 「正文」改為「引文」（或縮排）。

---

## 10. 程式碼（極少用到）

如果真的需要顯示原始 Markdown 範例或程式片段：

````markdown
```
這裡的內容不會被解讀為 Markdown
```
````

⚠️ **重要**：程式碼區塊內就算寫 `# 看起來像標題`，系統也**不會**把它當成 H1。所以如果你的標題抓不到，檢查是不是被誤放進程式碼區塊裡了。

---

## 11. 自動分頁規則

**不需要手動切頁**。系統會在以下情況自動斷頁：

- 內容溢出當頁高度時，下一段移到新頁
- 段落太長無法塞入一頁時，會在自然的字句邊界（透過二分搜尋）拆分
- 字體大小調整、橫/直書切換、視窗大小改變時都會**重新分頁**

### ❌ 不要使用的標記

- `分頁 1`、`# 分頁 2` 之類的手動分頁標記 — 系統會**直接刪除**這些行（為相容舊版本而保留）
- HTML 標籤如 `<br>`、`<div>` — 不保證能正常工作，請用 Markdown 語法
- Google Docs 的「插入 → 分頁符號」— 匯出 Markdown 時會被忽略

---

## 12. 直書中文與字型

- 預設字型：**標楷體** (DFKai-SB / BiauKai / 標楷體)
- 預設書寫方向：**直書（vertical-rl）**，從右到左
- 觀看時可以切換橫書 / 直書（按 `O` 鍵）
- 字級可調整（`Cmd/Ctrl + =/-/0`）

### 直書下的注意事項

- **英文與數字**在直書時會自動旋轉 90 度（直立顯示）
- **長英文段落**直書閱讀不好，建議翻成中文或拆短
- **標點符號**用全形（。，；：）不要用半形（. , ; :）

---

## 13. 上傳到 MasterSlides

完成編輯後：

1. 複製 Google Docs 的網址列（任何 `https://docs.google.com/document/d/<id>/...` 形式皆可）
2. 進入管理後台 `https://slides-6rb.pages.dev/admin/`
3. 貼上連結 → 系統會自動下載、轉換、儲存
4. 之後從清單點「播放」即可
5. 內容有更新時，於播放頁面按右下角的「重新整理」按鈕同步最新版

## 14. 常見問題

### Q：為什麼我加的圖片沒有出現？
A：通常是 Google Docs 分享權限沒開，或者用「來自網址」的外部連結圖。改成直接貼上圖片即可。

### Q：為什麼某段文字變成大標題了？
A：可能誤用了「標題 1」。選取該段 → 樣式 → 改為「標題 2」或「正文」。所有 Heading 1 都應該避免使用。

### Q：那簡報怎麼命名 / 識別？
A：請依靠 Google Docs 的「**文件名稱**」（畫面最上方那個檔名欄位）—— 它就是這份文件的 H1。內文不要再加 `#`，避免重複文件層級。

### Q：分頁很奇怪，某頁字很少／某頁字塞滿？
A：這是自然分頁的特性 — 它依照「能不能裝下」決定。可以調整字級或調整內容長度緩解。

### Q：表格內的圖片變形了？
A：表格在直書下會被轉成圖片，內含圖片時行為不穩。建議把圖片移到表格外。

### Q：我想預覽結果再正式發佈？
A：MasterSlides 沒有 staging 環境。建議的做法是建一份「測試副本」Google Docs，先上傳 / 預覽，確認 OK 再覆蓋正式版本（同樣的 `doc_id` 會直接覆寫）。

## 快速檢查清單（發佈前自查）

- [ ] 分享設為「擁有連結者均可檢視」
- [ ] **沒有任何「標題 1」(Heading 1)**，章節改用「標題 2」/「標題 3」
- [ ] Google Docs 的「文件名稱」（檔名）已取好，作為後台識別
- [ ] 所有圖片直接貼在 Google Docs 內（非外部連結）
- [ ] 沒有殘留的「分頁 N」手動標記
- [ ] 表格欄數 ≤ 4、內文不過長、不含圖片
- [ ] 重點用粗體或標題標示（不依賴底線/顏色）
- [ ] 標點符號用全形
